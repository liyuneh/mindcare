# Mood Translator

A responsive, no-build vanilla HTML/CSS/JavaScript app.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Type a phrase, optionally choose a mood, then translate.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design and motion
- `script.js` — rule-based translation engine, mode switching, random demo, clipboard, and LocalStorage history

## Notes
- No account, server, API key, or external AI service is required.
- Translation results are possibilities, not claims about anyone's actual emotions.
- History is stored in this browser/device using LocalStorage.
- Google Fonts are loaded from Google Fonts; system fallbacks are provided.
- This is a frontend prototype. For a future AI integration, call a secure backend endpoint; never put a private API key in `script.js`.
